# לזוז מבפנים

אתר חד עמודי לסדנאות ציור אינטואיטיבי של מיקה נדב.

אתר סטטי: HTML ו-CSS ו-JavaScript בקובץ אחד, בלי התקנות ובלי בנייה.

## מה בתיקייה

- `index.html` הדף כולו (מבנה, עיצוב והתנהגות)
- `media/` תמונות וסרטונים של האתר
- `assets/` הלוגואים
- `.nojekyll` מונע מ-GitHub Pages לעבד את הקבצים

## פרסום ב-GitHub Pages

1. מעלים את כל התוכן לריפו חדש ב-GitHub (הקובץ `index.html` צריך להיות בשורש).
2. ב-Settings, בקטגוריה Pages, בוחרים Deploy from a branch, את הענף `main` ואת התיקייה `/ (root)`.
3. אחרי דקה האתר זמין בכתובת `https://<שם-משתמש>.github.io/<שם-הריפו>/`.

אפשר לחבר גם דומיין משלך מאותו מסך.

## עריכה

- הטקסטים נמצאים בחלק ה-HTML שבתחתית `index.html`.
- הצבעים בתחילת העיצוב, בבלוק `:root`.
- הגלריות מוגדרות במשתנה `G` בתוך ה-script, ורוחב התמונות במשתנה `DIM`.
- פונטים (Varela Round ו-Assistant) נטענים מ-Google Fonts ולכן נדרש חיבור לאינטרנט.
